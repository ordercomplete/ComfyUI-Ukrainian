# Блок Знань Comfy-lady

> ⚙️ Канонічне джерело: `.github/knowledge-base/README.md`
> Редагуй там. Цей файл — робоча копія для завантаження знань.

## Призначення
Ця база зберігає знання про кодбейз, знайдені рішення та корисні посилання. Допомагає не шукати одне й те саме двічі.

## Структура

### code-patterns/ — специфічні патерни коду проекту
Записуй тут незвичні або важливі патерни, які зустрічаються в коді ComfyUI.

### solutions/ — знайдені рішення проблем
Коли вирішуєш складну проблему — записуй контекст і рішення.

### external-resources — корисні посилання з поясненням що дає
Посилання на документацію, статті, репозиторії, які дали відповідь на конкретне питання.

## Формат запису

```markdown
### Назва проблеми/патерну
**Дата:** YYYY-MM-DD HH:MM (актуальна на момент запису, перевіряй перед кожним новим записом)
**Контекст:** де в коді зустрічається (файли, функції)
**Рішення/Патерн:** що робити або як працює
**Джерело:** посилання (якщо з інтернету)
```

## Правила ведення:
- **Записи не видаляти.** Якщо інформація застаріла — додати новий запис з актуальною датою.
- **Актуальна дата й час** — перевіряй перед кожним новим записом.
- Старі записи залишаються як історія, щоб бачити еволюцію рішень.

## Коли додавати:
- ✅ знайшла незвичний патерн у коді ComfyUI — записати, щоб не шукати знову.
- ✅ вирішила складну проблему — записати рішення.
- ✅ посилання на документацію/статтю, яка дала відповідь.

## Коли НЕ додавати:
- ❌ очевидні речі (import os, def foo(): pass).
- ❌ загальновідоме Python без специфіки проекту.
