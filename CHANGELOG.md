# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2025-07-29

### Added
- Ініціалізація репозиторію української локалізації ComfyUI
- Повний текст GPLv3 ліцензії (без змін)
- NOTICE файл з атрибуцією оригінальним авторам
- Двомовний README.md (English + Українська)
- .gitignore з виключенням всіх типів моделей
- STRUCTURE.md з описом формату файлів локалізації
- CHANGELOG.md для історії змін
- MODELS.md з інвентаризацією локальних моделей
- Структура `locales/uk/` для перекладів
- UKRAINIAN_LOCALIZATION_PLAN.md з детальним планом впровадження

### Planned
- Переклад `main.json` (основні рядки UI)
- Переклад `nodeDefs.json` (назви вузлів)
- Переклад `settings.json` (налаштування)
- Переклад `commands.json` (команди)
- Локальне тестування
- Перший реліз v0.1.0
