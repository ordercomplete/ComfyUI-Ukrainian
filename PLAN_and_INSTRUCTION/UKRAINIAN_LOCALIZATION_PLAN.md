# План впровадження української локалізації ComfyUI

## Мета проєкту
Створити окремий репозиторій з повною українською локалізацією інтерфейсу ComfyUI та документацією локальних моделей.

---

## Архітектура ComfyUI: бекенд + frontend

Цей репозиторій є **форком ComfyUI (бекенду на Python)**. Frontend (TypeScript/Vue) — це окремий пакет, який встановлюється окремо.

### Як ComfyUI подає frontend користувачеві

1. **Бекенд** (`server.py`, рядки 239-243):
   ```python
   self.web_root = (
       FrontendManager.init_frontend(args.front_end_version)
       if args.front_end_root is None
       else args.front_end_root
   )
   ```

2. **FrontendManager.default_frontend_path()** (`app/frontend_management.py`, рядки 232-249):
   ```python
   import comfyui_frontend_package
   return str(importlib.resources.files(comfyui_frontend_package) / "static")
   ```

3. **Подання статичних файлів** (`server.py`):
   - `web.FileResponse(os.path.join(self.web_root, "index.html"))` — головна сторінка
   - `web.static('/', self.web_root)` — усі статичні файли (включаючи `locales/uk/*.json`)

### Чому `temp/ComfyUI_frontend` є тимчасовим

- **`temp/` виключено з `.gitignore`** (рядки 37, 68) — це тимчасова робоча папка
- **`temp/ComfyUI_frontend`** — це клон офіційного ComfyUI_frontend для розробки
- **Реальний frontend** використовується з pip-пакету `comfyui-frontend-package==1.44.19` (з `requirements.txt`)
- Клон використовується для: розробки перекладів, тестування, збірки влійного пакету

### Команда для швидкого запуску з українським frontend

```bash
# 1. Додати українську в localeConfig.ts
# 2. Скопіювати локалі
cp -r locales/uk/ temp/ComfyUI_frontend/src/locales/uk/

# 3. Збудувати frontend
cd temp/ComfyUI_frontend
pnpm install
pnpm build

# 4. Запустити з українським frontend
cd ../../
python main.py --front-end-root temp/ComfyUI_frontend/dist
```

## Використання ComfyUI_frontend для розробки

Репозиторій `temp/ComfyUI_frontend` є **офіційним клоном** ComfyUI frontend і містить:

### Корисні файли для розробки:
1. **`src/i18n.ts`** - реалізація завантаження локалей через Vue I18n
2. **`src/locales/localeConfig.ts`** - конфігурація підтримуваних мов (12 мов, української ще нема)
3. **`src/App.vue`** - головний компонент з інтеграцією i18n
4. **`src/stores/`** - зберігання налаштувань користувача
5. **`comfyui_frontend_package/`** - pip-пакет для інтеграції з ComfyUI бекендом
6. **`vite.config.mts`** - конфігурація збірки (Vite + Vue 3)

### Як додати нову мову (наприклад, українську):

```typescript
// 1. Створити папку locales/uk/
locales/
└── uk/
    ├── main.json
    ├── nodeDefs.json
    ├── settings.json
    └── commands.json

// 2. Додати в localeConfig.ts:
export const localeDefinitions = {
  // ... інші мови ...
  uk: { text: 'Українська', loaders: loadersFor('uk') }
}

// 3. Збудувати frontend:
pnpm build  # створює dist/ з українськими локалями

// 4. Запустити ComfyUI з влійним frontend:
python main.py --front-end-root temp/ComfyUI_frontend/dist
```

#### Двошарова архітектура ComfyUI локалізації

```
┌─────────────────────────────────────────────────────┐

│  comfyui_frontend_package/static/                   │
│    ├─ locales/uk/ ← джерело (TS/Vue)               │
│    └─ assets/ ← compiled bundles                    │
│        ├─ settings-CTZtNjCz.js  ← НАЙВАЖЛИВІШЕ    │
│        ├─ main-CNXm6Bpt.js      ← системні мітки   │
│        └─ GraphView-rB7Fd4WD.js ← граф нод         │
├─────────────────────────────────────────────────────┤
│  Settings Panel (Vue) ← бере переклади ТІЛЬКИ      │
│  з compiled JS bundles!                             │
└─────────────────────────────────────────────────────┘
```

1. **Зона 1 (Змінні)** — JavaScript змінні з name/tooltip
2. **Зона 2 (settings_default)** — short-hand посилання на змінні
3. **Зона 3 (export)** — експорт змінних для імпорту

Детальний опис: див. [UKRAINIAN_TRANSLATION_PLAN.md](UKRAINIAN_TRANSLATION_PLAN.md) → ЧАСТИНА 2
