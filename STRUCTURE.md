# Структура файлів локалізації

## Огляд

Цей документ описує структуру файлів української локалізації ComfyUI.

## Директорія локалізації

```
locales/
└── uk/
    ├── main.json          # Основні рядки інтерфейсу
    ├── nodeDefs.json       # Назви та описи вузлів
    ├── settings.json       # Налаштування інтерфейсу
    └── commands.json       # Команди меню
```

## Формат файлів

Всі файли локалізації використовують формат **JSON** з наступними правилами:

### 1. Структура JSON

```json
{
  "section": {
    "key": "Переклад",
    "nested": {
      "key": "Значення з {{placeholder}}"
    }
  }
}
```

### 2. Правила перекладу

- **Зберігати всі ключі** без змін
- **Зберігати placeholders** у форматі `{{variable}}`
- **Зберігати HTML теги** якщо вони є в оригіналі
- **Зберігати форматування** (зірки, дефіси, тощо)
- **Технічні терміни** залишати без перекладу або використовувати стандартні українські відповідники

### 3. Приклади

#### main.json
```json
{
  "common": {
    "cancel": "Скасувати",
    "confirm": "Підтвердити",
    "actions": {
      "save": "Зберегти",
      "delete": "Видалити"
    }
  }
}
```

#### nodeDefs.json
```json
{
  "KSampler": {
    "title": "КСамpler",
    "description": "Основний вузол для генерації зображень"
  }
}
```

#### settings.json
```json
{
  "general": {
    "language": {
      "label": "Мова інтерфейсу",
      "help": "Виберіть мову для відображення"
    }
  }
}
```

#### commands.json
```json
{
  "file": {
    "new": "Новий",
    "open": "Відкрити",
    "save": "Зберегти"
  }
}
```

## Спеціальні символи

### Placeholders
```json
{
  "welcome": "Ласкаво просимо, {{name}}!",
  "count": "Знайдено {{count}} результатів"
}
```

### HTML теги
```json
{
  "bold": "<strong>Важливо</strong>",
  "link": "<a href='{{url}}'>Посилання</a>"
}
```

### Спеціальні символи
```json
{
  "newline": "Перший рядок\nДругий рядок",
  "quote": "Він сказав: \"Привіт\""
}
```

## Валідація

### Перевірка JSON
```bash
# Перевірити валідність JSON
python -m json.tool locales/uk/main.json
```

### Перевірка ключів
```bash
# Порівняти ключі з English версією
python scripts/compare_keys.py locales/en/main.json locales/uk/main.json
```

## Інтеграція з ComfyUI

### Встановлення

1. **Копіювання файлів**:
   ```bash
   cp -r locales/uk /path/to/ComfyUI_frontend/src/locales/
   ```

2. **Перезапуск ComfyUI**:
   ```bash
   python main.py
   ```

3. **Вибір мови**:
   - Відкрийте ComfyUI в браузері
   - Перейдіть в Settings (⚙️)
   - Виберіть "Українська" зі списку мов

### Fallback механізм

Якщо певний ключ відсутній в українській версії:
1. Система автоматично використовує English версію
2. В консолі браузера з'явиться попередження
3. Інтерфейс продовжує працювати без помилок

## Робота з перекладами

### Додавання нового перекладу

1. Відкрийте відповідний файл (наприклад, `main.json`)
2. Знайдіть ключ в English версії: `locales/en/main.json`
3. Додайте переклад в українську версію:
   ```json
   {
     "newKey": "Новий переклад"
   }
   ```
4. Збережіть файл
5. Перевірте валідність JSON
6. Протестуйте в ComfyUI

### Оновлення існуючого перекладу

1. Знайдіть ключ в `locales/uk/main.json`
2. Оновіть значення:
   ```json
   {
     "existingKey": "Оновлений переклад"
   }
   ```
3. Збережіть файл
4. Протестуйте зміни

### Видалення перекладу

1. Видаліть ключ з української версії
2. Система автоматично використовує English fallback

## Найкращі практики

### 1. Збереження контексту
```json
{
  "save": "Зберегти",           // Кнопка
  "saveSuccess": "Збережено",   // Повідомлення
  "saveFailed": "Не вдалося зберегти"  // Помилка
}
```

### 2. Узгодженість термінології
- **Checkpoint** → "Чекпоінт" або "Контрольна точка"
- **LoRA** → "Лора" (залишити як LoRA)
- **Embedding** → "Ембедінг" або "Вектор"
- **VAE** → "VAE" (залишити як VAE)

### 3. Довжина рядків
- Намагайтеся зберігати схожу довжину з оригіналом
- Українські переклади часто довші - це нормально
- Тестуйте відображення в UI

### 4. Формальність
- Використовуйте форму "ви" для офіційних повідомлень
- Використовуйте форму "ти" для неформальних підказок
- Будьте послідовними в рівні формальності

## Тестування

### Чекліст тестування

- [ ] Всі рядки відображаються українською
- [ ] Немає зладаного форматування
- [ ] Placeholders працюють коректно
- [ ] Fallback на English для відсутніх ключів
- [ ] Відсутність RTL проблем
- [ ] Кодування UTF-8
- [ ] Відображення на різних розмірах екранів
- [ ] Правильне відображення спеціальних символів

### Поширені проблеми

1. **Зладаний JSON**: Завжди перевіряйте валідність перед комітом
2. **Відсутні placeholders**: Не видаляйте `{{variable}}` з перекладу
3. **Неправильне кодування**: Використовуйте UTF-8 без BOM
4. **Занадто довгі рядки**: Тестуйте в реальному UI

## Підтримка

### Оновлення перекладів

При оновленні ComfyUI:
1. Оновіть English файли з офіційного репозиторію
2. Порівняйте з українською версією
3. Додайте нові ключі
4. Оновіть змінені переклади

### Версіонування

- Версія локалізації відповідає версії ComfyUI
- Наприклад: `v1.0.0` для ComfyUI v1.0.0
- Збіг версій забезпечує сумісність
