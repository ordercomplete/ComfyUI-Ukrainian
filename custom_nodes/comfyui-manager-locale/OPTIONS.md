# Варіанти підключення JS перекладу Manager V4.2.1

## Варіант A: Vue extension
- Створити повноцінний Vue extension з `app.registerExtension()`
- Потрібен TypeScript, Vue components, збірка
- **Плюси:** Правильний спосіб ComfyUI
- **Мінуси:** Складно, багато коду, потрібна збірка

## Варіант B: Middleware ін'єкція ✅ (ВИБРАНО)
- Додати middleware яке ін'єктує `<script src="/comfyui-manager-locale/uk.js"></script>` в HTML відповідь
- Працює на рівні сервера, без збірки
- **Плюси:** Просте, надійне, без залежностей
- **Мінуси:** Ін'єкція в кожну HTML сторінку

## Варіант C: prestartup_script.py ін'єкція
- Використати `PromptServer.instance.routes` для реєстрації скрипту
- Потрібно знайти правильний хук
- **Плюси:** Без зміни HTML
- **Мінуси:** Не впевнена чи працює, мало прикладів
