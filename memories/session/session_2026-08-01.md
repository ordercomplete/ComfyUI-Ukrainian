### 🔄 Як працює перехоплювач
**Час:** 2026-08-01 12:55
1. loader.js чекає поки Manager завантажиться (100 спроб × 100мс)
2. Підключає manager-locale-uk.js через `<script>` тег
3. manager-locale-uk.js використовує MutationObserver
4. Спостерігає за появою `#cm-manager-dialog`

6. Додатково: інтервал перевірки кожні 1 сек (30 сек таймаут)

**Чому постійна:** Кожен tool call додає контекст → при 70-85% заповнення — модель "запилюється" → таймаут.
**Що можна зробити:** Детектування циклів, очищення контексту при 70%, скорочення tool call'ів.
**Що не можна:** Перехопити помилку в реальному часі, автоматично перезапустити запит.
