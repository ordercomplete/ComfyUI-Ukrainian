## 📊 ПЕРЕЛІК ВСІХ ВІДОМИХ МЕТОДІВ

### Метод 1: Vue I18n + Compiled Locale Bundle (Найнадійніший)

**Компоненти:** ComfyUI Core, KJNodes, Load3D  
**Принцип:** ComfyUI використовує Vue I18n для локалізації. Ukrainian locale bundle (`settings-{hash}.js`) завантажується динамічно при виборі мови.

**Як працює:**
1. `settingStore-pm7IqVHI.js` викликає `normalizeI18nKey()` для кожного ключа settings перед пошуком в об'єкті перекладів
2. `normalizeI18nKey()` робить: `key.replace(/\./g, "_")` — конвертує точки → підкреслення
3. Ukrainian locale bundle (`settings-CTZtNjCz.js`) містить об'єкт `settings_default` з перекладами

**Формат ключів:**
```javascript
// Правильно (shorthand properties):
KJNodes_canvasBg_thickness,  // → ключ "KJNodes_canvasBg_thickness" ✅

// Неправильно (string keys з точками):
"loramanager.trigger_word_wheel_sensitivity": variableName,  // → normalizeI18nKey() шукає "loramanager_trigger_word_wheel_sensitivity" ❌
```

**Рішення для TTS/LoRA:** Додати underscore-normalized версії всіх ключів в об'єкт `settings_default`:
```javascript
// Дублювати кожен ключ з обома форматами:
"loramanager.trigger_word_wheel_sensitivity": LoraManager_trigger_word_wheel_sensitivity,
"loramanager_trigger_word_wheel_sensitivity": LoraManager_trigger_word_wheel_sensitivity,  // underscore-normalized ✅
```

**Файли для редагування:**
- `comfyui_frontend_package/static/assets/settings-{hash}.js` — compiled locale bundle
- `comfyui_frontend_package/static/locales/uk/settings.json` — raw Ukrainian locale (не застосовується напряму!)

**Перевірка синтаксису:** `node --check "path/to/settings-{hash}.js"`

### Метод 2: External Locale-Patch System (Найпростіший)

**Компоненти:** KJNodes, VHS (VideoHelperSuite), Impact Subpack  
**Принцип:** Компонент реєструє extension через `app.extensionManager.register()` з методом `getTranslatedSettings()`, який повертає об'єкт з перекладами.

**Як працює:**
1. Component calls `app.extensionManager.setting.get('Comfy.Locale')` для визначення мови
2. Fetches locale JSON from `/custom_nodes/{component}/locales/${locale}/settings.json`
3. Merges translations into settings object via `getTranslatedSettings()`

**Формат ключів:** Snake_case без префікса (наприклад, `"strength_step"` замість `"loramanager.strength_step"`)

**Файли для редагування:**
- `{component}/locales/uk/settings.json` — переклади name/tooltip/options
- `{component}/web/comfyui/{component}.js` — логіка `getTranslatedSettings()`

### Метод 3: Internal $t() Function (Вимагає виправлення)

**Компоненти:** EasyUse  
**Принцип:** Компонент має власну i18n систему з функцією `$t()`.

**Проблема:** `$t()` перевіряє тільки `locale === 'zh-CN'`, Ukrainian fallback = English keys.

**Рішення:**
```javascript
// Замінити:
return locale === 'zh-CN' && cn ? cn : key

// На:
const isUkrainian = ['uk', 'uk-UA'].includes(locale)
if (isUkrainian && ukTranslations[key]) return ukTranslations[key]
return locale === 'zh-CN' && cn ? cn : key
```

**Файли для редагування:**
- `custom_nodes/comfyui-easy-use/web_version/v1/js/common/i18n.js` — виправити $t()
- `custom_nodes/comfyui-easy-use/locales/uk/nodeDefs.json` — створити новий

### Метод 4: Custom getLoraManagerLocale() + JSON Override (LoRA Manager)

**Компоненти:** LoRA Manager  
**Принцип:** Власна система перекладу з функцією `getLoraManagerLocale()` та `overrideLoraManagerSettings()`.

**Як працює:**
1. `getLoraManagerLocale()` перевіряє `Comfy.Locale` → завантажує відповідний JSON (`en.json`/`uk.json`)
2. `getTranslatedSetting()` шукає переклад у JSON за ключем без префікса `loramanager.`
3. `overrideLoraManagerSettings()` застосовує переклади до settings object

**Ключова проблема (виправлена 2026-08-01):**
- `getTranslatedSetting()` шукав у JSON ключі за повним ID: `"loramanager.strength_step"`
- Секція `settingsPanel` в `en.json`/`uk.json` має ключі **без префікса**: `"strength_step"`
- Виправлення: прибирати префікс `loramanager.` перед пошуком у JSON

**Файли для редагування:**
- `custom_nodes/comfyui-lora-manager/web/comfyui/settings.js` — `getLoraManagerLocale()`, `getTranslatedSetting()`
- `custom_nodes/comfyui-lora-manager/locales/uk/settings.json` — переклади name/tooltip

### Метод 5: XHR Loading + t() Function (rgthree-comfy)

**Компоненти:** rgthree-comfy  
**Принцип:** Компонент завантажує `settings.json` при старті через XHR, використовує функцію `t()` для перекладу.

**Проблема:**
- `main.json` існує але НЕ ЗАВАНТАЖУЄТЬСЯ жодним JS файлом (мертвий файл)
- One-time loading — не перезавантажується при зміні мови

**Рішення:**
1. Використовувати існуючу `t()` function для кожного hardcoded рядка
2. Додати event listener для `Comfy.Locale` changes у `config.js`

### Метод 6: MutationObserver + textContent Replacement (Manager V4.2.1)

**Компоненти:** ComfyUI Manager V4.2.1  
**Принцип:** Компонент НЕ має власної системи перекладів — текст жорстко закодований в JS файлах.

**Як працює:**
1. `manager-locale-loader.js` чекає поки Manager завантажиться (100 спроб × 100мс)
2. Підключає `manager-locale-uk.js` через `<script>` тег
3. `manager-locale-uk.js` використовує MutationObserver для спостереження за DOM
4. Після рендеру — перебирає всі елементи, перекладає за словником

**Файли для редагування:**
- `custom_nodes/comfyui-manager-locale/js/manager-locale-loader.js` — завантажувач
- `custom_nodes/comfyui-manager-locale/js/manager-locale-uk.js` — словник + MutationObserver

### Метод 8: DOM Override + setInterval + Option Translation Maps (VHS)

**Компоненти:** VHS (Video Helper Suite)  
**Принцип:** Компонент реєструє extension через `app.extensionManager.register()` з методом `getTranslatedSettings()`, але основний механізм — це **DOM override pattern** з `setInterval` для застосування перекладів до вже відрендерених елементів settings.

**Як працює:**
1. `loadVHSTranslations()` — XHR завантажує `locales/en/settings.json` та `locales/uk/settings.json` при ініціалізації (обидва мови одночасно)
2. `getVHSLocale()` — трирівнева перевірка: `app.ui.settings.getSettingValue('Comfy.Locale')` → `app.extensionManager.setting.get('Comfy.Locale')` → `navigator.language`
3. `vhsT(key, field)` — функція пошуку перекладу з fallback логікою (locale → 'en'), підтримка nested fields (`name`, `tooltip`)
4. `getTranslatedSettings()` — export для ComfyUI settings system (повертає settings array з перекладами)
5. **DOM Override** — `setInterval(overrideVHSSettings, 1000)` шукає `[data-setting-id^="VHS."]` елементи та замінює `textContent`/`title` атрибут
6. **Option Translation Maps** — окремі словники для combo-type settings (`optionTranslationMaps`)
7. **Category Headers Translation** — `translateCategoryHeaders()` зберігає префікси (емодзі) при заміні тексту

**Ключові особливості:**
- **Idempotency guard**: кожен елемент маркується `data-vhs-translated="true"`, наступні ітерації пропускають його (якщо locale не змінився)
- **Locale switch detection**: `checkLocaleSwitch()` порівнює поточний locale з попереднім → очищує всі маркери для повторного перекладу
- **English fallback**: при `locale='en'` використовує `ENGLISH_NAMES`/`ENGLISH_TOOLTIPS` для повернення англійського тексту (не просто порожній рядок)
- **Option translation maps**: окремі словники для кожного combo setting з масивами `{ en: [...], uk: [...] }`

**Формат ключів:** `VHS.{SettingName}` (наприклад, `"VHS.AdvancedPreviews"`)

**Рішення проблеми "показується при будь-якій мові":**
- Додано `if (lang === 'en') return 'en';` для обох основних джерел locale
- При `locale='en'` — `ENGLISH_NAMES`/`ENGLISH_TOOLTIPS` повертають англійський текст

**Файли для редагування:**
- `custom_nodes/comfyui-videohelpersuite/web/js/VHS.settings.js` — основний файл (398 рядків)
- `custom_nodes/comfyui-videohelpersuite/locales/uk/settings.json` — переклади name/tooltip/options
- `custom_nodes/comfyui-videohelpersuite/locales/en/settings.json` — англійські шаблони

**Перевірка синтаксису:** `node --check "path/to/VHS.settings.js"`

### Метод 7: API Endpoint + Fetch (TTS Audio Suite)

**Компоненти:** TTS Audio Suite  
**Принцип:** Компонент реєструє API endpoint `/api/tts-audio-suite/main-locale?locale=uk`, який повертає JSON з перекладами.

**Як працює:**
1. `tts-audio-suite-locale-patch.js` чекає поки `app?.settings` ініціалізується
2. Fetches locale from `/api/tts-audio-suite/main-locale?locale=uk`
3. Merges translations into settings object

**Проблеми:**
- Таймінг (5 сек таймаут може спрацьовувати раніше)
- API endpoint може повертати 404
- Мова 'uk-UA' замість 'uk'

**Рішення (виправлено 2026-08-03):**
1. Підтримка `'uk-UA'` та інших variantів мови (`lang.startsWith('uk')`)
2. Збільшено таймаут з 5 до 10/15 сек
3. Додано retry mechanism — перевірка кожні 500мс
4. Додано live language switching — polling кожну секунду

## 🎯 НАСТУПНІ ЗАВДАННЯ

### Додаткові методи, які було додано в аналізі

8. **Script‑Based Compiled Bundle Translation Update**  
   • **Коротко:** Скрипт `scripts/apply_node_defs_translations.py` автоматично оновлює compiled `nodeDefs-*.js`Bundle, вставляючи перекладені назви нод з `locales/uk/nodeDefs.json`.  
   • **Чому потрібний:** Уникнення ручного редагування великих bundle‑файлів; гарантія синхронізації після кожного `pnpm build`.  
   • **Як працює:**  
     1. Читає `locales/uk/nodeDefs.json`.  
     2. Патчить `nodeDefs-6_OSqomM.js` (або інший bundle) → додає `display_name`, `description`, `options` українською.  
     3. Зберігає оновлений bundle назад у `static/assets/`.  

9. **Dynamic Locale Reload via `Comfy.Locale` Event Listener**  
   • **Коротко:** Додає слухач `app.extensionManager.setting.addChangeListener((key)=>{if(key==='Comfy.Locale') loadTranslations();});`.  
   • **Чому потрібний:** При зміні мови в UI перекладні модулі оновлюються без перезапуску сторінки.  
   • **Реалізація:** У відповідних скриптах (`config.js`, `tts_audio_suite/tts-audio-suite-locale-patch.js`) викликати `loadTranslations()` у слухачі.  

10. **Automated Translation Generation from English Templates**  
    • **Коротко:** Скрипти `scripts/generate_uk_translations.py` та `scripts/sync_translations.py` створюють українські JSON‑файли, копіюючи структуру з англійських шаблонів.  
    • **Чому потрібний:** Швидке створення `main.json`, `settings.json`, `nodeDefs.json`, `commands.json` без пропусків.  
    • **Особливості:** Підтримка placeholder‑ів `{{variable}}`, ігнорування спеціальних тегів, автогенерація комментариев `// auto‑generated`.  

11. **Live Language Switching via Interval Polling**  
    • **Коротко:** Якщо подія `Comfy.Locale` не підтримує listener, використовується `setInterval(() => { if (app?.settings) loadTranslations(); }, 500);`.  
    • **Чому потрібний:** Перезавантаження перекладів у випадках, коли лайв‑подія не спрацює (наприклад, у старих версіях TTS Audio Suite).  

12. **Unified Translation Management Script**  
    • **Коротко:** CLI‑утиліта `scripts/build_frontend.py`, який:  
      - копіює `locales/uk/` у `temp/ComfyUI_frontend/src/locales/uk/`;  
      - додає `uk` у `localeConfig.ts`;  
      - запускає `pnpm build`;  
      - копіює `dist/` у `comfyui_frontend_package/static/`;  
      - виконує валідацію JSON‑файлів.  
    • **Чому потрібний:** Повна автоматизація процесу від перекладу до випуску, мінімізація ручних кроків.  

### Задача: LoRA Manager — Node Library (2026-08-03)
**Проблема:** У розділі "LoRA Manager" в Бібліотеці вузлів перекладені тільки заголовки. Setting names/tooltip/options залишаються англійськими.

**Причина:** Node Library використовує `nodeDefs.json` для відображення назв нод, а не `settings.json`. LoRA Manager має settings в `settings.json`, але node names — в `nodeDefs.json`.

**Рішення:** Додати переклади node names/inputs/outputs для LoRA Manager нод в `comfyui_frontend_package/static/locales/uk/nodeDefs.json`.

**Причина:** Та сама — Node Library використовує `nodeDefs.json`, а не `settings.json`.

## 💡 ІНСАЙТИ

1. **Найнадійніший механізм:** Vue I18n (ComfyUI Core, 3D) — lazy-load locale bundles
2. **Найпростіший механізм:** External locale-patch (KJNodes) — JSON override settings об'єктів
3. **Найскладніший механізм:** DOM replacement (Manager V4.2.1) — MutationObserver + textContent replacement
4. **Критична проблема:** One-time loading (TTS, rgthree) — не перезавантажується при зміні мови
5. **Рішення:** Додати event listener для `Comfy.Locale` changes у кожному компоненті
6. **Key normalization mismatch:** `normalizeI18nKey()` конвертує точки → підкреслення, тому ключі з точками не знаходяться в об'єкті перекладів
